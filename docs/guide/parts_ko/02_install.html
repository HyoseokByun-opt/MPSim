2. 설치와 첫 해석

2.1 설치

설치 방법은 두 가지입니다. 보안망의 PC처럼 인터넷이 막힌 PC에는 꾸러미를 통째로 복사해 설치하며, 이때 conda(Miniconda/Anaconda)도 필요 없습니다. 인터넷이 되는 PC라면 conda로 환경을 만들어도 됩니다.

상황실행할 파일필요한 것
인터넷이 없는 PC (권장)1_INSTALL_OFFLINE.bat 없음. Python과 NASA PuMA를 포함한 모든 패키지가 꾸러미 안에 들어 있습니다.
인터넷이 되는 PC1_INSTALL.bat conda. conda-forge에서 받아 env\에 환경을 만듭니다(약 2–3 GB).

오프라인 설치 (conda 없이)

  1. 받은 폴더 전체를 PC에 복사합니다. 짧은 경로에 두십시오(예: C:\MPSim\). 일부 패키지는 폴더를 깊게 만들기 때문에, 경로가 길면 Windows의 260자 경로 제한에 걸려 "file name too long"(WinError 206)으로 설치가 멈춥니다. 설치 스크립트가 경로가 길면 미리 알려 줍니다.
  2. 1_INSTALL_OFFLINE.bat — 인터넷을 전혀 쓰지 않습니다. 하는 일은 셋입니다.
    • runtime\의 Python 3.11 공식 런타임(python.org의 embeddable 배포판)을 python\ 폴더에 풉니다. Windows에 아무것도 등록하지 않습니다.
    • wheels\의 패키지 76개(NASA PuMA 포함)를 그 안에 설치합니다.
    • 모든 부품이 불러와지는지 확인하고, 짧은 자체검증(38개 항목)을 돌립니다.
  3. 2_RUN_LOCAL.bat — 실행합니다. 브라우저가 자동으로 열립니다.
설치는 옆에 python\ 폴더 하나를 만드는 것이 전부입니다(약 1.6 GB). 지우고 싶으면 그 폴더만 삭제하면 완전히 원상복구됩니다. 실행용 .bat 파일은 python\이 있으면 그것을 먼저 쓰고, 없을 때만 conda 환경을 찾습니다.

꾸러미의 구성

항목내용
runtime\python-3.11.9-embed-amd64.zipPython 3.11 공식 런타임(11 MB)
wheels\필요한 패키지 전부(휠 76개, 약 235 MB).
requirements-offline.txt설치할 패키지와 버전 — 자체검증을 통과한 그 버전입니다.
constraints-offline.txt넘으면 안 되는 버전(numpy < 2, scipy 1.11, vtk 9.5.2) — PuMA가 이 버전들로 빌드되어 있습니다.
tools\build_offline.py꾸러미를 만드는 스크립트(인터넷이 되는 PC에서 한 번).
tools\check_imports.py무엇이 불러와지고 무엇이 빠졌는지 보고합니다.

NASA PuMA를 conda 없이 쓸 수 있는 이유

PuMA는 conda-forge로만 배포되지만, conda 패키지가 실제로 설치하는 것은 평범한 Python 패키지(pumapy)입니다. 그 안의 컴파일된 모듈 네 개가 필요로 하는 것은 python311.dll, VCRUNTIME140.dll(모든 python.org Python에 들어 있음), 그리고 Windows 기본 C 런타임뿐이라, conda 환경의 다른 라이브러리에 기대지 않습니다. 그래서 tools\build_offline.py가 설치된 PuMA를 표준 휠 (pumapy-3.2.2-cp311-cp311-win_amd64.whl)로 묶고, 오프라인 PC에서는 이것을 다른 패키지와 똑같이 설치합니다. PuMA는 NASA Open Source Agreement 1.3으로 배포되며, 라이선스 파일이 휠 안에 함께 들어갑니다.

검증 — 이 꾸러미는 conda를 PATH에서 완전히 뺀 상태(Windows 기본 폴더만 남김)에서 설치해 확인했습니다. 짧은 자체검증 38개 항목과 전체 파이프라인 3개(충전 복합재, 박막, 다공체)가 모두 통과했고, 결과 수치는 conda 환경과 같았습니다(예: k = 0.4015 W/m·K).

꾸러미를 새로 만들 때 (인터넷이 되는 PC)

conda run -p .\env python tools\build_offline.py

Python 런타임을 받고, 그 PC의 conda 환경에 있는 PuMA로 휠을 만들고, 나머지 패키지를 Windows·Python 3.11용 휠로 모두 내려받습니다. 끝나면 폴더 전체를 오프라인 PC로 옮깁니다.

다른 PC에서도 쓰게 하려면

3_RUN_SERVER.bat으로 띄우면 같은 네트워크의 다른 PC에서 브라우저로 접속해 쓸 수 있습니다. 해석은 서버 PC가 수행하므로, 성능 좋은 PC 한 대에 띄워두고 여러 사람이 쓰는 방식이 효율적입니다. 접속이 안 되면 4_NETWORK_CHECK.bat이 방화벽 문제인지 무선 격리 문제인지 구분해 알려줍니다.

프로그램 실행은 반드시 .bat 파일로

번호가 붙은 .bat 파일은 _common.bat을 통해 어떤 Python을 쓸지 (python\ → env\ → conda 환경 순서) 정하고, 콘솔 인코딩을 UTF-8로 맞춥니다. 항상 .bat 파일로 실행하십시오.

2.2 첫 해석 따라하기

처음이라면 프리셋에서 시작하는 것이 가장 빠릅니다. 아래 순서대로 하면 5분 안에 첫 결과를 볼 수 있습니다.

① 프리셋 고르기

Home 탭 왼쪽 패널에 전형적인 문제들이 준비되어 있습니다. 예를 들어 EMC · epoxy + fused silica 50 vol%를 누르면 재료·구조·해석 항목이 한 번에 채워집니다. 각 프리셋 아래에는 어떤 해석이 켜지는지 표시되어 있습니다.

② 구조 만들어 보기

Structure 탭으로 가서 Generate structure를 누릅니다. 해석은 하지 않고 구조만 만들어 3D로 보여줍니다. 필러가 원하는 만큼 들어갔는지, 크기가 적절한지 눈으로 먼저 확인하는 단계입니다. 이렇게 만든 구조는 그 런에 저장되어, 이어서 ⑤에서 해석을 돌리면 구조를 다시 만들지 않고 그대로 씁니다(2.4절).

③ 해상도 정하기

Domain 탭에서 복셀 크기와 RVE 크기를 볼 수 있습니다. 처음에는 자동 설정을 그대로 두어도 됩니다. 값을 바꾸면 화면 아래에 예상 격자 크기가 바로 표시되고, 기준에 못 미치면 경고가 뜹니다(6장).

④ 해석 고르기

Simulation과 Structure Analysis 탭에서 필요한 항목을 켭니다. 여러 개를 한 번에 켤 수 있습니다. 리본의 아이콘을 눌러 켜고 끌 수도 있고, 왼쪽 카드의 스위치로도 됩니다.

⑤ 실행

오른쪽 위 Run을 누릅니다. 아래 Console에 진행 상황이 흐르고, 중간 결과가 나오는 대로 표시됩니다. 끝나면 자동으로 Result Viewer가 열립니다.

2.3 처음 돌릴 때 권하는 설정

항목권장이유
Accuracy levelFast로 시작 경향을 보는 데는 충분하고 훨씬 빠릅니다. 보고용 수치가 필요할 때 Standard 이상으로 다시 돌립니다.
Load directionsz, x, y 모두 이방성이 있는지 확인할 수 있습니다. 시간이 급하면 z(두께 방향)만 켜도 됩니다 — 장(field)과 화살표는 첫 방향인 z로 저장됩니다.
해석 항목필요한 것만 탄성(Elasticity and CTE)은 하중 7개를 풀어야 해서 가장 오래 걸립니다. 나중에 해석을 추가해도 구조는 다시 만들지 않습니다(2.4절).
Realisations1회 편차를 보려면 2회 이상으로 늘리면 95 % 신뢰구간이 함께 나옵니다.
해석 시간은 격자 크기의 세제곱에 비례해 늘어납니다. 복셀 크기를 절반으로 줄이면 격자는 8배가 되고 시간은 그보다 더 늘어납니다. 처음에는 거칠게 시작해 필요한 만큼만 올리는 편이 좋습니다.

2.4 같은 구조로 해석을 이어 가기

런(run)은 자신이 만든 구조를 structure\ 폴더에 보관합니다(복셀 지도와 입자 목록). 새 해석을 시작할 때 프로그램은 같은 작업 폴더·케이스의 런 가운데 같은 구조(형상·크기·함량·격자·접촉 처리·seed가 같은 것)를 찾고, 있으면 다음처럼 처리합니다.

상황결과
Generate structure 후 Run 구조만 있던 그 런이 해석 런으로 이어집니다. 구조를 다시 만들지 않고, 런이 하나 더 생기지도 않습니다.
해석이 끝난 런에 해석 항목만 추가(예: thermal → thermal + dielectric) 그 런이 이어집니다. 이미 있는 해석은 그대로 두고 새 항목만 계산하여 결과·보고서·3D 장에 합칩니다. 폴더 이름도 담긴 해석에 맞게 바뀝니다(thermal → dielectric+thermal).
새 항목이 없음"이미 모두 들어 있다"고 알리고 계산하지 않습니다.
재료 물성이나 해석 옵션을 바꿈 결과가 달라지므로 새 런이 생깁니다. 다만 구조는 앞 런의 것을 그대로 가져다 씁니다 — 이전 결과는 보존됩니다.
형상·함량·격자·seed를 바꿈다른 구조이므로 새로 생성합니다.

화면에 열려 있는 런이 조건에 맞으면 그 런을 우선합니다. 이 동작을 원하지 않으면 Simulation 탭의 Reuse the structure of a matching run을 끕니다.
