27. 보고서와 파일 내보내기

해석이 끝나면 프로그램이 보고서를 자동으로 만들어 둡니다. 따로 정리할 필요 없이, 그대로 보내거나 인쇄할 수 있는 형태입니다.

27.1 Report 탭

보고서는 위에서부터 다음 순서로 구성됩니다.

구성내용
제목과 이력 해석 이름, 프로그램 버전, 실행 일시, 소요 시간, 사용한 솔버가 한 줄로 기록됩니다. 예시 A는 "MPSim 1.0.0 · 2026-09-17 10:22:04 · elapsed 98 s · solver NASA PuMA (periodic finite elements)"입니다.
Verification 한 줄 "24 passed · 3 warnings · 0 failed". 보고서를 받은 사람이 가장 먼저 봐야 할 줄입니다(31장).
대표값 타일 밀도, 열전도도, Dk, Df, CTE, 영률, 입자 수 등 핵심 값이 큰 글씨로 나옵니다. 각 타일 아래에 방향별 값도 작게 붙습니다.
1. Input 어떤 재료를 어떤 형상·함량으로 넣었는지. Role / Name / Shape and size / Content / Principal properties 열로 정리됩니다.
2. RVE model 격자 크기, 복셀 크기, 구조 그림.
해석별 절 실행한 각 해석의 결과 표와 그림.
검증 상세 점검 항목 전체와 통과·경고·실패.
입력이 결과와 함께 기록된다는 점이 중요합니다. 물성값만 적힌 표는 몇 달 뒤에 보면 어떤 조건이었는지 알 수 없습니다. 이 보고서는 입력·해상도·버전·검증 결과를 모두 담고 있으므로, 그 자체로 재현 가능한 기록이 됩니다.

27.2 세 가지 내보내기

단추무엇이 나오는가언제 쓰는가
Open in a new tab 보고서를 새 탭에서 엽니다. 브라우저에서 그대로 인쇄하거나 PDF로 저장할 수 있습니다. 빠르게 확인하거나 PDF로 남길 때
Save HTML 그림까지 하나의 HTML 파일에 담아 저장합니다. 외부 파일에 의존하지 않으므로 그 파일 하나만 보내면 됩니다. 메일로 보낼 때. 받는 사람은 브라우저로 열기만 하면 됩니다.
Complete ZIP 보고서와 함께 원본 데이터 전부를 묶습니다 — 결과 JSON, 구조 파일, 필드 데이터, 그림. 다른 사람이 결과를 다시 열어 보거나 재해석해야 할 때

27.3 그 밖의 내보내기

위치내보내는 것
DOE 탭의 CSV 모든 케이스의 인자와 응답을 표로 저장합니다. 스프레드시트나 다른 분석 도구로 넘길 때 씁니다(28장).
3D 화면의 그림 저장 현재 화면 그대로의 PNG, 또는 서버에서 다시 렌더링한 고해상도 그림. 논문·발표 자료용입니다(26장).
작업 폴더 해석마다 폴더가 하나씩 생기며 모든 산출물이 그 안에 있습니다. 구성은 부록 C를 보십시오.
보고서를 다른 사람에게 보낼 때는 Verification 줄을 함께 설명해 주십시오. 경고가 있는 값을 아무 말 없이 전달하면, 받는 사람은 그 값을 확정된 물성으로 받아들이게 됩니다. 경고의 뜻과 대응은 31장에 정리되어 있습니다.
