MPSim

Material Property Simulation
User Guide — v5
A program that builds the microstructure of a semiconductor material, solves the physical
equations inside it and returns its thermal, electrical, mechanical and flow properties.

This guide is written for readers who have never run a simulation before.
Readers who measure properties in the laboratory will find, for every quantity,
"how it is measured in an experiment, and how it is obtained in the calculation"
side by side — those passages are a good place to start.

The names of the controls are quoted exactly as they appear on screen,
so every term in this guide can be found in the program as written.
