27. Reports and file export

When an analysis finishes, the program writes a report automatically. No tidying up is needed: it is ready to send or print as it is.

27.1 The Report tab

From the top, the report contains:

PartContent
Title and history The run name, program version, date and time, run time and solvers in one line, e.g. "MPSim 1.0.0 · 2026-09-17 10:22:04 · elapsed 98 s · solver NASA PuMA (periodic finite elements)" for example A.
Verification line "24 passed · 3 warnings · 0 failed" — the line a recipient of the report should read first (chapter 31).
Headline tiles Key values in large type: density, thermal conductivity, Dk, Df, CTE, Young's modulus, particle count and so on, each with its per-direction values in small type below.
1. Input Which materials went in, with which shapes and contents, in the columns Role / Name / Shape and size / Content / Principal properties.
2. RVE model Grid size, voxel size, picture of the structure.
Sections per analysis Result tables and figures of each analysis run.
Verification details All check items with pass, warning and failure.
That the input is recorded with the results matters. A table of property values alone says nothing about the conditions a few months later. This report holds the input, resolution, version and verification, so it is a reproducible record in itself.

27.2 Three exports

ButtonWhat it producesWhen to use it
Open in a new tab Opens the report in a new tab, from which the browser can print it or save it as PDF. A quick look, or keeping a PDF
Save HTML Saves the report with its figures in one HTML file, independent of other files — send that single file. E-mailing; the recipient just opens it in a browser.
Complete ZIP Bundles all the raw data with the report — result JSON, structure file, field data, figures. When someone else must reopen or re-analyse the results

27.3 Other exports

WhereWhat it exports
CSV in the DOE tab Factors and responses of all cases as a table, for spreadsheets or other analysis tools (chapter 28).
Figure saving in the 3D view A PNG of the current view, or a high-resolution figure re-rendered on the server, for papers and presentations (chapter 26).
Work folder Every run gets its own folder holding all outputs; see Appendix C for its layout.
When sending a report to someone, explain the Verification line with it. A value with warnings passed on without comment will be taken as a settled property. The meaning of the warnings and what to do about them are in chapter 31.
